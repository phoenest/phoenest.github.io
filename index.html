phoenest

An old phone, reborn as a hardened, always-on server for AI coding agents.

You tell a frontier coding agent, in plain language: "turn my old phone into a coding server." It probes the device, decides an install path the hardware can actually support, does the work that can be automated, and pulls you in only for the physical steps like unlocking or flashing.

A co-pilot, not a turnkey installer. It won't get every phone right on day one — it's built to be finished by hand and to get smarter as a community.

The flow

detect → decide a path → guide the human gates → build → harden → watch (external dead-man) → report, and record what worked in a device knowledge base.
